# Nuc-CAD

## 如何打包：

- 安装好所有依赖，在开发环境中确定能够"npm run start"运行程序后：

- 在该目录下在 Terminal 输入："npm run build"进行编译

- 修改 main.js 文件 mainWindow.loadURL 切换路径

- 继续在 Terminal 输入："npm run packager-linux"

- 打包完成后，在该目录下在 Terminal 输入："npm run create-debian-installer"

- 安装文件出现在本地该目录的/build 文件夹里

- 在需要部署的电脑上运行安装文件

## 如何部署：

- radyn_station 安装包：双击后按提示进行安装

- 算法镜像：压缩文件复制到本地后 docker load -i $name.tar 解压镜像

- wkhtmltox 0.12.6 安装包：双击后按提示进行安装

- 手动创建部分:error_report 文件夹, config.json

- 其他如 mongodb 等的部署与 PET 和 SPECT 相同
